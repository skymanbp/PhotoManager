    计划

    pm 的一切写盘都是两段式：先生成计划，再 pm apply <id> 执行；执行后可 pm undo 回滚。这里只看，不执行。

    类型计划 id生成时间项待执行跳过待裁决
    选一个计划查看明细

    三步上手

    1. 看状态：左侧「状态」一眼看清三件事——Raw / 成片 / 相册各多少、相册与 vault 差哪些、备份盘上次什么时候同步。
    2. 分类推送：「分类推送」里给每张 NEW 照片选 landscape / portrait / urban，点「生成推送计划」。这一步只写计划文件，不碰照片。
    3. 执行：在终端跑页面给出的 pm apply <id>；执行是校验写入 + 日志，随时 pm undo。之后按提示做 git 提交（pm 从不替你执行 git）。

    安全模型：GUI 是独立进程，从不直接触碰照片文件；一切经 pm serve 的本机 API。pm 没有删除与覆盖原语——唯一的移出机制是带清单的隔离区。
