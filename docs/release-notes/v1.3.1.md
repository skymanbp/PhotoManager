## 1.3.0 → 1.3.1

**先看这两条**

- **两条提示指错了地方，已改正**。`pm vault status` 的 UNPUSHABLE 行和 `pm vault hold` 拒收非 jpg 时，都说「→ 归档页「非 jpg 转换」」；1.3.0 把那张卡的标题改成了「非 jpg 转成 jpg」，照着找会找不到。现在两处都指「非 jpg 转成 jpg」。
- **更正 1.3.0 发布说明的一句话**。1.3.0 说「所有按钮名与 1.2.1 相同」，这句不对：归档页三个出计划的按钮改了短名——「生成归档计划」→「扫描并归档」、「加入相册（生成计划）」→「加入相册」、「转换并生成计划」→「转换」。它们做的事与执行链没有变。

**文档与测试**

- 文档漂移哨兵 `caseGuiOneClick` 多钉一条：源码里「某页「名字」」这种指路话，名字必须真在页面上。它在修之前判红，抓到的正是这两条提示和一处注释。
- 设计文档（DESIGN-GUI、DESIGN-P8）、安装包简介、两份 README 里 1.3.0 漏改的旧卡名、旧按钮名同步改正。
- 三本 PDF 手册（仓外、不入库）按 1.3.0 界面就地修订：操作手册 v11 → v12（改 19 页，末尾加一页修订说明）；GUI 一键操作图册改 14 页，末尾加一页；傻瓜版重排一页，多一行「提示先 pm scan → 按 1 点扫描」。
