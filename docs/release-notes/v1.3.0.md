pm 1.3.0 —— GUI 一键面与瘦身：GUI 里能扫描了、能一键打开命令行了、每页只剩一句话和一个主按钮。照片与盘上格式零改动，命令行全部不变。

## 1.2.1 → 1.3.0

**先看这三条**

- **GUI 里能扫描了**。此前归档页点「生成归档计划」，遇到刚放进暂存区的新文件会答「暂存区与索引不一致 → 先 pm scan」，而 GUI 七页里没有一处能扫描，只能开终端。现在：状态页右上有**「扫描」**按钮；「现在该做什么」里的「索引已过期」那条点一下就扫；归档页第一张卡改成**「扫描并归档」**——先扫索引，再出归档计划，一次点完。走的是与终端 `pm scan` 完全相同的代码（第十三个写端点 `POST /api/scan`），只写主库 `.pm` 里的索引，照片不动。
- **一键打开命令行**。状态页 vault 卡「复制上线命令」旁边多了**「打开命令行」**：在展示集仓目录（没配就 portfolio 仓，再没配就主库）开一个 cmd 窗口，`pm` 已在 PATH 上——把复制好的上线命令粘进去、看清、回车。pm 仍然**不替你执行 git**，窗口里敲什么由你定。
- **瘦身**：每页一句副标题 + 一个主按钮，长说明收进「说明」折叠区（想看再点）；侧栏图标改成数字 = 数字键 1–7；状态页「现在该做什么」提到最上面、每条都能点；设置页只留主库 / vault 目录 / 备份盘三张常用卡，其余收进「高级设置」；出计划之后横幅末尾多一个「去「计划」页执行」按钮。**功能一个没少、行为一个没改**：所有按钮名、输入项、端点与执行链与 1.2.1 相同（元素 id 也没动，脚本逻辑不变）。

**行为变化**

- `pm serve --writable` 现在开十三个写端点（多了 `POST /api/scan`）；`--writable` 的帮助文本、DESIGN §14、DESIGN-GUI、README 同步。
- pm-ui 的 Rust 壳多了一个 Tauri command `open_terminal`（除 spawn / 交 token / kill 之外的第四件事）；它只开窗口，不执行任何东西。
- 状态页「备份盘未登记」那条待办改成跳到「设置」页登记（此前是一行终端命令）。

**文档与测试**

- 新增 `caseServeScan`（扫描端点：只读拒、写级扫完新文件进索引、照片零改动）与 `caseGuiOneClick`（页面按钮 / 端点 / command 注册 / 归档先扫后出计划 / 页面不再指人去终端跑 pm scan）。
- 测试 508 → 510，GHC 警告 0。
- 三本 PDF 手册（操作手册 / GUI 图册 / 傻瓜版）里的截图仍是 1.2.1 的界面，按钮名未变、步骤仍成立；重生成另行安排。

## 安装

- `pm-ui_1.3.0_x64-setup.exe`：安装包（装到当前用户，不要管理员权限）。
- `pm-1.3.0-windows-x64.zip`：免安装，含 `pm.exe`（CLI）与 `pm-ui.exe`（GUI）。
- 两个资产都没有代码签名，首次运行 SmartScreen 会提示「未知发布者」。
